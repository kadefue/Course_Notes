## 📖 Course Overview

**ABE 715: Computer Programming** is an advanced postgraduate computational course offered by the Department of Agricultural Engineering at Sokoine University of Agriculture. The course is tailored to equip postgraduate engineers with high-level computational, numerical, and algorithmic skills necessary to solve complex research problems in agricultural and biosystems engineering.

Students transition from basic algorithmic logic to building end-to-end data processing pipelines using Python, numerical calculus, computer vision, machine learning, and geospatial spatial analytics.

---

## 🎯 Target Audience & Degree Programs

This course directly serves graduate engineering students in two premier master's programs:

1. **MSc in Irrigation Engineering and Management (MSc IEM)**:
   * **Hydrological Modeling**: Numerical integration of hydrographs and discharge curves using Simpson's and Trapezoidal rules.
   * **Geospatial & Remote Sensing Analytics**: Raster processing with GeoPandas and GDAL to evaluate watershed soil-water indices, digital elevation models (DEM), and canal routing.
   * **Telemetry & Automation**: Integrating IoT data streams from remote weather stations, soil moisture telemetry, and automated canal gates.

2. **MSc in Agricultural and Biosystems Engineering (MSc ABE)**:
   * **Biosystems Modeling**: Implementing numerical root finding (Newton-Raphson, Bisection) to solve non-linear mechanical and biological equilibrium equations.
   * **Computer Vision**: Utilizing OpenCV for automated crop phenotype grading, canopy coverage segmentation, and weed detection.
   * **Data Science & ML**: Predictive modeling of machinery telematics, yield forecasting, and post-harvest quality kinetics.

## 🗺️ Syllabus & Lecture Topics Breakdown

The curriculum is delivered across 16 core lecture modules:

| Lecture | Topic | Focus & Engineering Application |
| :--- | :--- | :--- |
| **Lec 1** | **Introduction to Advanced Programming** | Computational architectures, Python 3 environment, Colab/Jupyter workflows. |
| **Lec 2** | **Python Fundamentals** | Typing, memory references, dynamic variables, and standard libraries. |
| **Lec 3** | **Control Flow & Logic** | Conditional branches, algorithmic complexity, and exception handling. |
| **Lec 4** | **Loops & Iteration** | High-performance iteration, list comprehensions, and generators. |
| **Lec 5** | **Data Structures** | Custom lists, dictionaries, sets, tuples, and memory overhead optimization. |
| **Lec 6** | **Functions & Modules** | Reusable modules, lambdas, scope resolution, and unit testing. |
| **Lec 7** | **NumPy & Pandas Pipelines** | Multi-dimensional array vectorization, tabular data wrangling, and missing data imputation. |
| **Lec 8** | **Data Visualization** | Engineering plots with Matplotlib/Seaborn: contour plots, time series, and dual-axis charts. |
| **Lec 9** | **Numerical Methods: Root Finding** | Bisection, Newton-Raphson, and Secant methods for implicit agricultural equations. |
| **Lec 10** | **Numerical Integration** | Trapezoidal rule, Simpson's $1/3$ and $3/8$ rules for flow volume and cumulative heat units. |
| **Lec 12** | **Computer Vision in Biosystems** | Image thresholding, morphological transformations, contour detection with OpenCV. |
| **Lec 13** | **Machine Learning Basics** | Supervised learning, linear/polynomial regression, classification, and model validation. |
| **Lec 14** | **IoT Integration** | MQTT client implementation, REST APIs, JSON parsing from edge sensors. |
| **Lec 15** | **Geospatial Data Analysis** | Coordinate reference systems (CRS), raster masking, NDVI computation, spatial buffers. |
| **Lec 16** | **Course Review & Future Trends** | Edge AI, distributed computing, and emerging trends in AgriTech 4.0. |
